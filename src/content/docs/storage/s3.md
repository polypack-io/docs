---
title: S3 Storage
description: Polypack supports S3 file storage.
lastUpdated: 2025-04-03
---

S3 file storage allows you to use cloud providers, or your own hardware and software, to store and serve files. This allows you to create ephemeral instances of the platform and enable easy scalability.
